# چوبینه | لندینگ پیج سه‌بعدی لوازم دکوری و چوبی

لندینگ پیج فارسی (RTL) با فونت **Vazir** برای برند فرضی «چوبینه»، با ساختار و انیمیشن‌هایی الهام‌گرفته از دموی [company.wbrk.ir/demo3](https://company.wbrk.ir/demo3/).

## ✅ امکانات پیاده‌سازی‌شده
- **هدر دو‌طبقه** مثل سایت مرجع: نوار بالا (لوگو، جستجو، حالت تاریک، سبد خرید، ورود) + نوار منوی تیره با **مگامنو** سه‌ستونه با بنر، دراپ‌داون، خط زیر متحرک و تلفن با افکت زنگ. هنگام اسکرول به پایین پنهان و به بالا ظاهر می‌شود.
- **منوی موبایل**: کشوی کناری با انیمیشن پلکانی + **منوی پایین ثابت موبایل** (مثل مرجع).
- **هیرو سه‌بعدی با Three.js**: اشیای چوبی سه‌بعدی (برش تنه درخت، کاسه، گلدان، قاشق، مکعب، تخته) با بافت چوب رویه‌ای، ذرات خاک‌اره، حرکت با موس؛ برش مورب پایین، متن تایپ‌شونده، استک آواتار مشتریان، کارت‌های شناور و تصویر با افکت Tilt سه‌بعدی.
- **نوار شمارنده‌ها** با انیمیشن شمارش و اعداد فارسی.
- **خدمات ما** (کارت‌های ۴تایی با خط رنگی، آیکون چرخشی سه‌بعدی، شماره‌ی توخالی) + بنر تماس.
- **محصولات پرفروش**: اسلایدر Swiper با فیلتر دسته‌بندی، علاقه‌مندی، مشاهده سریع و افزودن به سبد (ذخیره در localStorage).
- **درباره ما** با تصاویر لایه‌ای شناور، بج تجربه، شمارنده‌ها و دکمه‌ها.
- **پروژه‌های ما**: آکاردئون تصویری شماره‌دار ۰۱ تا ۰۴ + نوار آمار و امضای مدیرعامل (مثل مرجع).
- **ویدیو/تور کارگاه**: دکمه پخش با موج پالس، باز شدن مودال اسلایدشو Ken Burns.
- **نظرات مشتریان** (اسلایدر)، **سوالات متداول** (آکاردئون نارنجی مثل مرجع) با **مکعب چوبی سه‌بعدی CSS** به‌جای Q فلزی.
- **افتخارات** + **مارکی لوگو همکاران**، **مقالات** با کاروسل مرکزی (مثل مرجع)، فرم تماس، فوتر.
- حالت تاریک/روشن، نوار پیشرفت اسکرول، دکمه بازگشت به بالا با حلقه پیشرفت، پیش‌لودر، انیمیشن‌های ورود AOS.

## 📍 مسیرها
- `index.html` — صفحه اصلی؛ بخش‌ها: `#hero-section`, `#services-section`, `#products-section`, `#about-section`, `#projects-section`, `#video-section`, `#testimonials-section`, `#faq-section`, `#honors-section`, `#blog-section`, `#contact-section`
- `css/style.css`، `js/hero3d.js` (صحنه سه‌بعدی)، `js/main.js` (تعاملات)

## 🗄 داده‌ها
- جدول `contact_requests` (name, phone, source) — فرم تماس با `POST tables/contact_requests` ذخیره می‌شود.
- سبد خرید، تم و علاقه‌مندی‌ها: localStorage.

## 🖼 تصاویر
تصاویر واقعی از جستجوی اینترنتی (دکوراسیون چوبی، ساعت، ظروف، شلف، جاشمعی، کارگاه نجاری). آواتارها از pravatar.cc. برای استفاده تجاری، تصاویر اختصاصی خودتان را جایگزین کنید.

## ⏳ پیاده‌نشده / پیشنهادها
- صفحات جداگانه محصول، سبد خرید و پرداخت واقعی (نیازمند بک‌اند)
- ورود/ثبت‌نام واقعی (در سایت استاتیک امن نیست)
- جایگزینی ویدیوی واقعی کارگاه به‌جای اسلایدشو
- پنل مدیریت محصولات از طریق Table API
